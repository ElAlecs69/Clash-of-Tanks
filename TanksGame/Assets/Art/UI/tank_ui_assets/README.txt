TANK UI ASSET PACK

Estructura:
background/  Fondo del campo de batalla
buttons/     Botones principales
frames/      Marcos y estructuras
panels/      Paneles y texturas
icons/       Iconos y controles
skins/       Vista previa y patrones
misc/        Detalles metálicos e insignias

Los elementos fueron organizados como PNG individuales a partir del diseño conceptual.
Para una implementación de UI escalable se recomienda usar los marcos como base
para crear componentes 9-slice/nine-patch.
